# Currículo Web Responsivo

## 📌 Sobre o projeto
Projeto desenvolvido com o objetivo de criar um currículo online moderno, responsivo e acessível, permitindo a visualização das minhas experiências profissionais, cursos, habilidades, certificações e demais informações relevantes de forma organizada e interativa.

A aplicação foi construída pensando tanto na navegação web quanto na compatibilidade para impressão.

---

### 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

---

### 🎯 Funcionalidades
- Exibição de experiências profissionais
- Apresentação de cursos e certificações
- Layout responsivo para diferentes dispositivos
- Navegação simples e intuitiva
- Compatibilidade para impressão
- Organização visual das informações profissionais

---

### 📱 Responsividade
O projeto foi desenvolvido utilizando conceitos de responsividade para adaptação em:
- Desktop
- Tablets
- Smartphones
- Modo de impressão

---

### ▶️ Como abrir o projeto

Basta abrir o arquivo `http://dan-dias.github.io` no navegador.

---

### 🎨 Objetivo do projeto
- Praticar desenvolvimento web
- Aplicar conceitos de HTML, CSS e JavaScript
- Criar uma apresentação profissional online
- Desenvolver uma interface responsiva e amigável
